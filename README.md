Mobiiliohjelmointi kurssin lopputyönä tein budjetti- ja kuitintallennussovelluksen. 

Työssä käytetyt teknologiat/ kirjastot ovat:
- React Native & TypeScript
- Expo Router
- Expo SQLite
- Expo Image Picker
- Expo File System
- Expo Vector Icons

Moni teknologia/kirjasto oli tuttu jo kurssin materiaalista joten niihin ei tarvinnut hakea hirveästi tietoa. 
Yhteenveto sivun kaavion/kaavioiden tekoon meinasin käyttää aluksi **react-native-gifted-charts** tai **react-native-chart-kit** kirjastoja mutta päädyin käyttämään pelkää React Nativen **View** komponenttia kaavionpalkkin tekoon. 

Expo SQLiten kanssa oli vähän hankaluuksia koska en osaa SQL-kieltä kovin hyvin, mutta Expon omasta [SQLite dokumentaatiosta](https://docs.expo.dev/versions/latest/sdk/sqlite/) ja VSCoden sisäisestä copilotista oli paljon hyötyä ja niiden avulla sain tietokannan toimimaan.
Expo FileSystemistä löytyi myös hyödyllistä tietoa [Expon dokumentoinnista](https://docs.expo.dev/versions/latest/sdk/filesystem/). Halusin myös lisätä navigointipalkkiin ikonit jotka sain [Expo Vector Iconeista](https://docs.expo.dev/guides/icons/).
